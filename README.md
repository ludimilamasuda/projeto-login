# Projeto Login

Tela de login com tema escuro, validação de campos via JavaScript.

## Funcionalidades
- Login com validação de campos
- Dashboard pós-login
- Cadastro de usuário

## Branches utilizadas
- main
- develop
- feature/validacao
- feature/dashboard
- feature/cadastro-usuario
- hotfix/erro-html
- release/v1.1.0

## Como executar
Abra o arquivo index.html no navegador.
